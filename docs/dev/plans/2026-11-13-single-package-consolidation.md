# Single Package & Crate Consolidation Plan (`@unikit-bridge/rustra` + `unikit-bridge`)

## Goal & Scope (G0)

Consolidate the repository's distribution surface into a single npm package (`@unikit-bridge/rustra`) and a minimal 2-crate Rust set (`unikit-bridge` + `unikit-bridge-macros`), while preserving the `unikit` CLI behavior and providing deprecation tooling and migration documentation for legacy `rustra` / `@rustra/*` and the 9 superseded `@unikit-bridge/*` packages.

### User Decisions

- **npm**: Consolidate all 9 publishable packages (`@unikit-bridge/{types,node,bun,tauri,react-native,react,testing,devtools,cli}`) into a single publishable npm package **`@unikit-bridge/rustra`** (`packages/rustra`) with subpath exports and `bin: { "unikit": "./dist/cli/index.js" }`.
- **crates.io**: Keep **`unikit-bridge`** + **`unikit-bridge-macros`** (2 crates; eliminate **`unikit-bridge-naming`**). Consumer `Cargo.toml` depends only on `unikit-bridge`.
- **Legacy `rustra` deprecation**: Maintain deprecation tooling and migration documentation for legacy `rustra` / `@rustra/*` as well as the 9 superseded `@unikit-bridge/*` npm packages and `unikit-bridge-naming` crate.

### Acceptance Criteria (`AC-*`)

- **AC-1 (Single npm package `@unikit-bridge/rustra` & CLI preservation)**:
  - `packages/` contains only one publishable package `@unikit-bridge/rustra` (`packages/rustra/package.json`), with `files: ["LICENSE", "dist", "native/**/*", "fixtures", "unikit.schema.json"]`, `engines: { "node": ">=18" }`, `peerDependencies: { "react": ">=18.0.0", "react-native": ">=0.76" }`, and `peerDependenciesMeta: { "react": { "optional": true }, "react-native": { "optional": true } }`.
  - Root export `"."` re-exports `./types/index.js`, and subpath exports cover `./types`, `./node`, `./bun`, `./tauri`, `./react-native`, `./react`, `./testing`, `./devtools`, `./cli`, `./cli/schema`, `./cli/generate`, `./cli/schema-diff`, `./cli/validate-engine`, `./cli/vite`, `./vite`, and `./unikit.schema.json`.
  - `bin.unikit` (`./dist/cli/index.js`) preserves all 8 existing CLI subcommands (`generate`, `codegen`, `init`, `setup`, `diff`, `doctor`, `inspect`, `dev`), `--version`/`--help`, and `UsageError` exit code `2` contract, verified in unit tests and packed-tarball execution.
- **AC-2 (Minimal Rust crates `unikit-bridge` + `unikit-bridge-macros`)**:
  - `crates/unikit-bridge-naming` is deleted and removed from `Cargo.toml` workspace/dependencies, `crates/unikit-bridge/Cargo.toml`, `crates/unikit-bridge-macros/Cargo.toml`, `fuzz/Cargo.lock`, and `.github/workflows/release.yml`.
  - `snake_to_lower_camel` moves into `crates/unikit-bridge/src/naming.rs` (with tests in `crates/unikit-bridge/tests/naming.rs`) and an identical internal copy in `crates/unikit-bridge-macros/src/naming.rs`, verified for zero drift by `scripts/architecture-boundaries.mjs`.
  - Empty leftover directories `crates/rustra*` on disk are removed.
- **AC-3 (Codegen, CLI & Examples Alignment)**:
  - Rust codegen (`crates/unikit-bridge/src/package_types_gen.rs`, `package_commands_gen.rs`, `codegen_names.rs`) and TypeScript CLI (`packages/rustra/src/cli`) emit `@unikit-bridge/rustra/*` imports (`@unikit-bridge/rustra/types`, `/node`, `/bun`, `/tauri`, `/react-native`).
  - CLI `init` / `setup` / `doctor` / `react-native` resolve `native/` and `unikit.schema.json` inside `@unikit-bridge/rustra`, scaffold single-dependency `package.json` templates (`@unikit-bridge/rustra`), emit ONLY `unikit-bridge = "${v.cargoRange}"` in consumer `Cargo.toml` `[dependencies]` (no `unikit-bridge-macros`), while repo checkout patch scripts (`onboarding-gate.mjs`, `quick-start.mjs`, `ci.yml`) patch `[patch.crates-io]` for both `unikit-bridge` and `unikit-bridge-macros` (and not `unikit-bridge-naming`).
  - All in-repo `examples/*` manifests, lockfiles/configs/imports, and `examples/*/generated/*` are updated and regenerated cleanly.
- **AC-4 (Tooling, Gates, CI & Release Workflows)**:
  - `cliManifest.unikitTemplate` is simplified to `{ "cargoRange": "...", "npmRange": "..." }`, kept coherent by `scripts/version-packages.mjs` and `scripts/check-release-coherence.mjs`.
  - Root `package.json`, `bun.lock`, `eslint.config.js`, `tsconfig.eslint.json`, `typedoc.json`, `.changeset/config.json`, `scripts/*` (including `architecture-boundaries`, `react-doctor-gate`, `check-test-list-parity`, `check-release-docs`, `check-react-native-package`, `check-packed-react-native-consumer`, `audit-release-registry`, `registry-consumer/*`), `.github/workflows/*.yml`, and `api-surface/snapshot.json` are updated so all local build, lint, format, unit, contract, codegen-freshness, onboarding, docs, and packed-consumer gates pass.
- **AC-5 (Deprecation & Migration Preservation)**:
  - Note: No active `rustra` / `@rustra/*` manifests currently exist in the repository; deprecation covers previously published packages/crates and migration guidance.
  - `scripts/deprecate-legacy-packages.mjs` (dry-run by default; `--apply` required for actual `npm deprecate` calls; unit-tested via `scripts/deprecate-legacy-packages.test.mjs` and registered in `test:release-tools`) covers:
    - Superseded npm packages (9): `@unikit-bridge/types`, `@unikit-bridge/node`, `@unikit-bridge/bun`, `@unikit-bridge/tauri`, `@unikit-bridge/react-native`, `@unikit-bridge/react`, `@unikit-bridge/testing`, `@unikit-bridge/devtools`, `@unikit-bridge/cli` → each pointing to `@unikit-bridge/rustra` (and its subpath export or `unikit` bin).
    - Legacy `rustra` npm packages: `rustra`, `@rustra/types`, `@rustra/node`, `@rustra/bun`, `@rustra/tauri`, `@rustra/react-native`, `@rustra/react`, `@rustra/testing`, `@rustra/devtools`, `@rustra/cli` → each pointing to `@unikit-bridge/rustra` (ignoring unpublished 404s cleanly when checking/applying).
    - Legacy crates.io crates guidance: prints/verifies `cargo yank --version <ver>` instructions (and executes only with explicit `--crates --crate-version <ver> --apply`) for `unikit-bridge-naming`, `rustra`, `rustra-macros`, and `rustra-naming` pointing consumers to `unikit-bridge`.
  - Migration and documentation updates (`docs/migrations/package-consolidation.md`, `docs/migrations/package-consolidation.ko.md`, `README.md`, `README.ko.md`, `docs/README.md`, `docs/README.ko.md`, `docs/getting-started*.md`, `docs/compatibility-matrix*.md`, `docs/release-procedure*.md`, `docs/migration-guide*.md`, `docs/versioning-policy*.md`, `docs/registry-onboarding*.md`, `docs/dev/internal/crate-structure*.md`) accurately document `@unikit-bridge/rustra` + `unikit-bridge` and legacy `rustra` / `@unikit-bridge/*` deprecation, passing `bun run test:docs`.

## Architecture Decisions (G1)

1. **Single Package Layout (`packages/rustra/`)**:
   - Subdirectories under `packages/rustra/src/`: `types/`, `node/`, `bun/`, `tauri/`, `react-native/`, `react/`, `testing/`, `devtools/`, `cli/`, plus root `src/index.ts` re-exporting `./types/index.js`.
   - `packages/rustra/native/` holds RN C++/ObjC++/JNI sources; `packages/rustra/fixtures/` holds testing fixtures; `packages/rustra/unikit.schema.json` sits at package root.
   - Internal cross-module imports inside `packages/rustra/src/` use relative paths (`../types/index.js`, `../react-native/index.js`) so `tsc` builds the package in one pass cleanly.
   - Path-depth & fixture adjustments inside `packages/rustra`:
     - `src/cli/cli-runtime.ts`: reads `../../package.json` (valid from `dist/cli/cli-runtime.js` and `src/cli/cli-runtime.ts`).
     - `src/testing/index.test.ts`: resolves `../../fixtures/schema.sample.json`.
     - `src/cli/config-validation.test.ts`: resolves `../../unikit.schema.json` (line 297) and `../../package.json` (line 355).
     - `src/bun/index.test.ts:9`: `repoRoot` uses 4 `'..'` (`'..', '..', '..', '..'`) to reach repository root from `packages/rustra/src/bun/`.
     - `src/cli/cli-init.test.ts:476,524`: `repo` resolves `'../../../../'` instead of `'../../../'` (from `dist-test/cli/`).
     - `src/cli/cli-init.test.ts:482,556,564-567`: `[patch.crates-io]` fixture removes `'unikit-bridge-naming'` (uses `['unikit-bridge', 'unikit-bridge-macros']`) and symlinks `packages/rustra` to `node_modules/@unikit-bridge/rustra`.
     - `src/cli/init-template.ts`: sets `INIT_CONFIG_SCHEMA_PATH = './node_modules/@unikit-bridge/rustra/unikit.schema.json'`, emits `@unikit-bridge/rustra` single npm dependency (in `dependencies`, since it ships runtime adapters + CLI) and `unikit-bridge` single Rust dependency.
     - `src/cli/react-native.ts`: searches `node_modules/@unikit-bridge/rustra` and validates `manifest.name === '@unikit-bridge/rustra'`.
     - `dependencies` in `packages/rustra/package.json`: `"picomatch": "^4.0.7"`, `"smol-toml": "^1.9.0"`.
     - `devDependencies` in `packages/rustra/package.json`: `"@types/bun": "^1.4.0"`, `"@types/node": "^26.3.0"`, `"@types/picomatch": "^4.0.3"`, `"@types/react": "^19.0.0"`, `"@types/react-dom": "^19.0.0"`, `"@types/react-test-renderer": "^19.0.0"`, `"react": "19.3.0"`, `"react-dom": "19.3.0"`, `"react-test-renderer": "19.3.0"`, `"typescript": "^5.9.0"`.
